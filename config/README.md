# Configuration Examples

These files are examples, not authoritative plugin state.

- `quickadd.example.json` contains two relative-path capture choices.
- `templater.example.json` points to `99_Templates` and disables system commands.

Back up an existing vault and merge individual settings through the plugin UI when possible. Do not overwrite plugin data blindly. Community-plugin schemas can change between releases.

The example files contain no API provider configuration, credential field, shell path, user-home path, or private vault name.
