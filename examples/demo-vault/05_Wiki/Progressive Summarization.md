# Progressive Summarization

## In one sentence

Progressive summarization compresses a source in stages so the most reusable ideas become easier to retrieve without discarding context.

## Explanation

Start with the source, mark the useful passages, restate the central ideas, and finally write a short synthesis in your own words. Each layer should remain linked to the source.

## When it is useful

- turning reading notes into a project brief;
- finding the central point of a long source;
- creating a durable note that can support more than one project.

## Evidence and limits

- Compression can remove nuance, so keep a source link.
- Not every captured item deserves a durable wiki note.
