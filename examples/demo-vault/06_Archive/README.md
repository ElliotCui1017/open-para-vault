# Archive

Use this folder for completed, cancelled, or inactive material that still provides context.

Before moving a note in a real vault:

1. confirm it is no longer active;
2. record the outcome or reason;
3. check important wikilinks;
4. move it deliberately rather than deleting it automatically.
